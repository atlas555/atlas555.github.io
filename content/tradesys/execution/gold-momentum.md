## 2. Gold Momentum信号设计

### 2.1 信号逻辑

Plan E3中"Gold Momentum"不是简单的"买入持有黄金"，而是**趋势跟踪信号控制的黄金仓位**：

```
IF 黄金价格 > 200日移动平均线 THEN 持有黄金(IAUM)
ELSE 持有现金(BIL)或不持仓
```

### 2.2 为什么用200日均线而非其他信号？

| 信号 | 优点 | 缺点 | 适用性 |
|------|------|------|--------|
| 200日SMA | 简单、鲁棒、百年验证 | 滞后 | ✅ 最适合散户 |
| 50/200日金叉 | 减少假信号 | 更滞后 | 🟡 可选 |
| 12个月回报>0 | 与TSMOM一致 | 等效于~252日SMA | ✅ 备选 |
| RSI/MACD | 更灵敏 | 过度交易、假信号多 | ❌ 不适合 |

**推荐使用200日SMA**，理由：
- Moskowitz et al. (2012) 的12个月TSMOM信号本质上等效于价格vs ~252日前价格
- Hurst et al. (2017) 百年数据验证了长期趋势信号在商品上的有效性
- 简单=容易坚持执行=散户最大的优势

### 2.3 当前信号状态（2026-03-20）

GLDM从$109.74跌至$89.07（-18.8%），52周低点$58.56。关键问题：**当前价格是否仍在200日均线之上？**

粗略估算：
- 52周范围 $58.56 - $109.74
- 如果过去200天均匀分布在$70-$110之间，200日SMA大约在$85-$90
- 当前$89.07**可能正好在200日SMA附近**——这是一个临界点

**反直觉发现 #2**：黄金在2026年3月正处于200日均线的关键测试位。如果跌破，动量信号会翻转为"不持有"。这意味着**现在不是入场的好时机**——应该等信号明确后再行动。

## 4. 执行方案

### 4.1 入场规则

```
条件: IAUM收盘价 > 200日SMA 且 连续3个交易日站稳
行动: 买入IAUM，占组合15%（$750 ≈ 16股@$45）
```

### 4.2 退出规则

```
条件: IAUM收盘价 < 200日SMA 且 连续3个交易日跌破
行动: 卖出全部IAUM，资金转入BIL
```

### 4.3 "连续3日"缓冲的理由

单日穿越200日SMA可能是噪声。要求连续3日确认可以过滤掉约70%的假信号（基于历史回测经验值）。代价是延迟3天入场/退出，但对季度再平衡的散户来说影响极小。

### 4.4 与DBMF的关系

DBMF（管理型期货ETF）内部已经包含了黄金期货的趋势跟踪头寸。单独配IAUM 15%是否重复？

**不完全重复**，理由：
1. DBMF的黄金头寸通常只占其投资组合的5-10%
2. DBMF用**期货**交易黄金，我们用**现货ETF**——结算方式不同
3. DBMF可能在黄金趋势反转时已经减仓，而我们的IAUM是独立信号
4. 但两者**在黄金大趋势中会正相关**——这是需要接受的

**如果希望避免重叠**：可以将GoldMom的15%并入DBMF（总计60%DBMF），但这会增加对单一基金经理的依赖。
