## 18:58 — Star Office 状态桥接修复

- Bug：AI晓龙在 Star Office UI 中状态一直显示「休息中」
- 根因：Stellar agent 没有配置向 Star Office 推送状态的机制，join 后状态从未更新
- 修复方案：在 Mission Control server.py 中加了后台桥接线程，每 30 秒：
  1. 从 sessions_list 获取所有 agent 的 session 状态
  2. 推断状态（running subagent → researching, heartbeat → syncing, feishu → writing, cron → executing, 其他 → idle）
  3. 主 agent（娃彩）直接写 state.json
  4. 远程 agent（AI晓龙）通过 `/agent-push` API 推送
- 验证：AI晓龙状态已从 idle 变为 executing（定时任务执行中）
